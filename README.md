# 📱 Task Manager Application

An Android-based **Task Management System** that enables admins to assign tasks, monitor progress, and communicate with employees efficiently. The app includes chat, notifications, and analytics features for better workflow management.

---

## 🚀 Features

### 👨‍💼 Admin
- Assign tasks to employees
- Set deadlines
- Monitor task progress
- Send complaints
- Chat with employees
- View analytics dashboard (charts)

### 👨‍🔧 Employee
- View assigned tasks
- Mark tasks as completed
- Receive complaints
- Chat with admin
- Get notifications

### 💬 Chat System
- WhatsApp-style UI
- Message bubbles (left/right)
- Seen/unseen messages
- Timestamp support

### 🔔 Notifications
- New messages alerts
- Complaint alerts
- Task updates
- Unread badge system

### 📊 Analytics Dashboard
- Total tasks
- Completed & pending tasks
- Top employee
- Pie chart & bar graph

---

## 🛠️ Tech Stack

- **Language:** Java  
- **Platform:** Android SDK  
- **Database:** SQLite  
- **UI:** Material Design, RecyclerView, Navigation Drawer  

---

## 🗄️ Database Tables

- **Users** → login, role  
- **Tasks** → task details  
- **Chat** → messages  
- **Complaints** → admin messages
